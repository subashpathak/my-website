# One Book, One Idea

A personal reading log. One book, one durable idea.

## How publishing works

This is a static site. To publish an entry, send the book title, author, and
the one durable idea worth keeping in chat, and the page is updated and pushed
live immediately.

## Files

- `index.html` — the entire site, self-contained.
- `README.md` — this file.
