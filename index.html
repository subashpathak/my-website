One-time setup. Publishing writes straight to this site’s files on GitHub, so the page needs a token that is allowed to do that. The token is stored only in this browser, never sent anywhere except GitHub.
  1. Open github.com/settings/tokens and choose Generate new token.
  2. Under Repository access pick Only select repositories and choose my-website.
  3. Under Permissions set Contents to Read and write, then generate the token.
  4. Copy it and paste it below.
