# Portfolio Maintenance Skill

When updating or maintaining this personal website, follow these strict execution rules to keep the layout minimal, lightweight, and easy to access.

## Core Directives

1. **Keep it Minimal:** Do not add complex UI frameworks, bloated styling, or unnecessary scripts. The website must load exceptionally fast and maintain a clean, text-first design.
2. **Top Bar Integrity:** Ensure the header always retains exactly these links:
   * **Home / Contact Info** (Subash Pathak)
   * **Movies/Series**
   * **Books**
   * **Blog**
3. **Markdown-First Content:** All blog posts, book reviews, and movie lists must be stored as clean, structured Markdown files. Keep formatting consistent across all content directories.
